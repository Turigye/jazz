Privacy

There is nowhere to send it.

Cloud dictation tools answer "is my audio safe?" with certifications. Jazz answers it with architecture: there is no server, no account and no upload path. The model sits on your disk and runs on your GPU.

Try this

Turn off Wi-Fi. Nothing changes.

Downloading your model is the only thing Jazz ever uses the network for. After that it has no reason to reach out and no code that does. This page holds itself to the same line — its typefaces are served from here, not from a font CDN, and the build refuses to publish if that ever stops being true.

The meter

The needle is not a bar chart.

A real VU meter deflects linearly with voltage, not decibels — which is why the numbers on its face bunch up at the quiet end. The needle has mass, so it overshoots a transient by a few percent and settles back.

Jazz models both: a damped spring driven by the actual amplitude of your voice. It is the same code moving the needle at the top of this page.

Questions

Before you download.

Is it really free?

Yes, and there is no tier above it. No account, no trial, no card. The source is public and you can build it yourself if you'd rather.

Does it genuinely work offline?

Yes. After the one-time model download the app makes no network requests. Turn off Wi-Fi and dictation is unchanged.

How accurate is it?

The default model has a 2.8% word error rate — roughly one word in thirty-five, and usually a proper noun. The dictionary exists to fix the ones that matter to you.

Does it change what I said?

Only in ways you configure: filler words removed, your dictionary applied, your snippets expanded. There is no AI rewriting step, so it can't quietly reword you.

Why Apple Silicon only?

The speech model runs on the GPU through Metal. Intel Macs have no equivalent path fast enough to be pleasant. Windows and Linux builds exist on other branches but predate this version.

What permissions does it ask for, and why?

Microphone, to hear you. Accessibility, so the hotkey works while another app is focused and so it can paste into it. macOS asks for both itself — Jazz never sees your password, and neither grant gives it network access.

Where do my transcripts go?

Into a local file so you can re-insert a recent one from the menu bar. Clear them any time in Settings.
